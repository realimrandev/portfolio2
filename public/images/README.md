# Images

## REQUIRED: `imran.jpg`

The site's About page, Navbar avatar, and SEO meta-tags all reference
`/images/imran.jpg`. Save your portrait photo here as **`imran.jpg`**.

- **Path**: `public/images/imran.jpg`
- **Recommended size**: at least 800×1000 (4:5 portrait), JPEG quality 85+
- **Aspect**: anything works — Next.js `<Image>` will crop with `object-cover`

## Optional

- `og.png` (1200×630) — Open Graph social share image
- Any other local image assets

Remote images (Unsplash, Pexels, etc.) are already whitelisted in
`next.config.ts` and need no local file.
